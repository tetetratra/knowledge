# 「社会保険・労働保険のしくみと手続き」

- 「社会保険・労働保険のしくみと手続き」
- **PART1 社会保険・労働保険の全体像**
  - 公的保険 (PART1)
    - 労働保険 (PART2)
      - 労災保険 (PART3)
      - 雇用保険 (PART4)
    - 社会保険 (PART5)
      - 健康保険 (PART6)
      - 厚生年金保険 (PART7)
      - 国民保険 (PART7)
      - 国民健康保険
      - 介護保険
      - etc...
  - 保険者：保険を運営する主体
  - 被保険者：保険に加入した人
  - 電子申請
    - 社会保険のほとんど ＋ 雇用保険の多く の手続きで利用可
    - Egov
    - 流れ
      - 電子証明書の取得
      - 申請データを作成
      - 申請データに電子署名して送信
      - 役所到達
  - パートの保険
    - 正社員と同じ働き方なら同じ保険に入らなければならない
    - 保険と条件
      - 労災保険
        - 無条件で加入
      - 雇用保険
        - ↑20h/w
      - 健康保険
        - 正社員の3/4以上の労働時間
      - 厚生年金保険
        - 正社員の3/4以上の労働時間
- **PART2 労働保険のしくみ**
  - 労災保険は全額事業主
  - 雇用保険は事業主と被保険者で分担
  - 事業場ごとに適用
    - 「適用事業所」
  - 労災保険と雇用保険は基本的には同時に行われる
    - 「一元事業者」
  - 労働保険事務組合に委託できる
    - 中小企業のみ
  - 6月に納付する
    - 「年度更新」
    - 概算を先払い & 昨年分を生産
  - 賃金の見込みから算出
    - 手当とかは含まれるけれども、祝い金系は含まれない
    - ボーナスは含まれる
  - 事業の種類ごとに保険料率や負担割合は違う
    - 通信業は保険料率が0.25%で、負担割合は（事業主：従業員 ＝ 2：1）
- **PART3 労災保険のしくみ**
  - 仕事中の事故
  - 特別加入
    - 第一種特別加入者
      - 中小企業の事業主とその家族
      - 役員
    - 第二種特別加入者
      - 特定の事業
    - 第三種特別加入者
      - 海外に派遣される人
  - 保証内容
    - 療養
    - 休業
      - 休業給付(60%)と休業特別支援金(20%)で、80%もらえる
    - 二次健康診断
- **PART4 雇用保険のしくみ**
  - 雇用保険の給付を「失業等給付」という
    - 求職者給付
      - 基本手当など
      - 高年齢求職者給付金
    - 就職促進給付
      - 就職促進手当
    - 雇用継続給付
      - 育児休業給付
      - 介護休業給付
    - 教育訓練給付
      - 教育訓練給付金
  - 公共職業安定所＝ハローワーク
  - 学生や公務員は雇用保険の適用外
  - 2年以上の保険加入期間が必要
    - 倒産や解雇の場合は例外
  - 支給日額 ＝ 賃金日額 × 給付率（50~80%）
  - 給付期間は、保険者期間や退職理由や年齢で決まる
    - 自己都合（全年齢）
      - 1~10年で90日
    - 解雇・倒産など
      - 若者ならだいたい90日~
  - 病気とか、都合があれば支給を延長できる
  - 「雇用保険被保険者証」
    - 雇用保険に加入していたことの証明
  - 自己都合退職の場合は、3ヶ月の給付制限がある
  - ハローワークの斡旋を拒否したりすると給付が先延ばしになる
  - 「雇用の継続が困難になる理由」の場合にも雇用保険から給付される
    - 「育児休業給付」
      - 育休
      - 賃金の50%
      - 1歳未満の子の養育
      - 休業前から給料が変わっていなければ対象外
    - 「介護休業給付」
    - 「高年齢雇用継続基本給付金」
- **PART5 社会保険のしくみ**
  - 事業主と従業員で折半
  - 健康保険と厚生年金保険はセットで手続きされがち
  - 事業所単位
  - 会社の場合は社長とかも含めて全員が被保険者となる
  - 個人事業者の場合は被保険者になれない
    - 「適用除外」
  - 給与額から保険料が決まる
    - 定時改定の手続きで報酬を申告
      - 社会保険では給与のことを報酬という
      - 「健康保険・厚生年金保険被保険者報酬月額算定基礎届（算定基礎届）」
      - 「健康保険。厚生年金保険被保険者報酬月額算定基礎届総括表」
    - 賞与を出したときも申告
      - 「健康保険厚生年金保険被保険者賞与支払届」
  - 従業員に関する色々な届出
    - 入社時
      - 「雇用保険被保険者資格取得届」
      - 「健康保険被保険者資格取得届」
      - 「健康保険被扶養者（異動）届」
        - 雇った人に被扶養者がいるとき
    - 氏名の変更
      - 「健康保険厚生年金保険被保険者氏名変更（訂正）届」
    - 扶養の追加（配偶者）
      - 「健康保険被扶養者（異動）届」
    - 住所変更
      - 「健康保険厚生年金保険被保険住所変更届」
      - 扶養者の住所変更なら
        - 「国民年金第3号被保険者住所変更届」
    - 扶養の追加（出産）
      - 「健康保険被扶養者（異動）届」
      - 「健康保険出産育児一時金支給申請届」
        - 42万円が支給される
      - 「健康保険出産手当金支給申請書」
    - そのほかのケースでも被扶養者の増減があったとき
      - 「健康保険被扶養者（異動）届」
  - 事業所の移転や事業主の変更のときとかも各種届出が必要
  - 源泉徴収
    - 所得税を給与から予め引いておくこと
- **PART6 健康保険のしくみ**
  - 健康に関することでもらえる
  - 業務中なら労災保険。業務外なら健康保険
  - 運営によって保険の呼び方が違うらしい
    - 「全国健康保険協会」が保険者の健康保険は「全国健康保険協会管掌健康保険（協会けんぽ）」
    - 「健康保険組合」が保険者の健康保険は「組合管掌健康保険」
  - 健保と国保
    - 健康保険と国民健康保険は別物
    - 国民健康保険
      - 自営業者、無職者が入る
      - 市区町村が保険者
  - 被扶養者になる条件
    - 年収130万未満
    - 保険者の年収の半分以下
    - 別居の場合、被扶養者の年収が仕送りより少ないこと
  - 保険金が支給されるのは本当に病気や怪我のときだけ
    - 少しでも適用外の治療が入ってくると全部適用外になる
    - 最先端の治療などは保険外併用療養費といい、併用OKだが、この部分の治療費は保険の対象外となる
  - 三割負担
  - 高額の治療には高額療養費が給付される
    - 額は年収に逆進
    - 月収28~50万だと、医療費が`8万 + (総医療費 - 27万) * 0.01`を超えた分が支給される
  - 介護費用にも高額治療に似たような制度がある？
    - 高額治療と介護費用を合算して限度を超えると更にもう少しもらえる
  - 業務外の怪我で働けなくなった場合は傷病手当金がもらえる
    - 収入の2/3を、1年6ヶ月目までもらえる
  - 出産の場合も、怪我とは別の制度だけれども、休業分の収入と一時金がもらえる
  - 被保険者も2~3割負担で医療を受けられる
  - 会社の退職後は、自分で保険を選んで入る必要がある
    - すべての国民は医療保険に入らねばならないという法律がある
    - 選択肢
      - 任意継続保険者になる
        - 退職後も2年間その会社のときの健康保険に入れる
      - 扶養者側になる
      - 特例退職被保険者？ になる
      - 国民健康保険に入る
  - 収入の1割くらいが保険料で、事業者と折半だから5%くらい
- **PART7 年金制度のしくみ**
  - 運営主体による分類
    - 公的年金
      - 国が運営
    - 企業年金
      - 企業（多分雇用先の企業）が運営
    - 個人年金
      - 商売な年金のこと？
  - 国民年金
    - 国民全員が加入
    - いわゆる「年金制度の1階部分」
  - 厚生年金保険
    - 会社員になると加入
    - 「2階部分」
  - 3階部分は企業年金とか雑多な色々
  - 被保険者の分類
    - 第1号被保険者
      - 国民年金にのみ加入している
    - 第2号被保険者
      - 厚生年金保険まで加入している
    - 第3号被保険者
      - 第2号の専業主(婦/夫)
  - 今は65歳から年金を受け取れる
    - 将来的には70,75歳から？
  - 国民年金の保険料免除
    - 学生
  - 10年以上の加入が必要
  - 保険料を払っていた月数で年金額が決まる
    - 40年払うと満額。年78万
  - 厚生年金の保険料
    - 給料から天引きして、天引きと同額を雇用主も拠出する
    - 今は約18%。半分だから9%
  - 年金受給後も働く場合、支給が減額されることもある
  - 病気や怪我で障害を負った場合、国民年金保険から障害基礎年が支給される
