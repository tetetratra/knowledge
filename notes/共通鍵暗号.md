# 共通鍵暗号

## 暗号と認証のしくみと理論がこれ1冊でしっかりわかる教科書

- [図解即戦力 暗号と認証のしくみと理論がこれ1冊でしっかりわかる教科書：書籍案内｜技術評論社](https://gihyo.jp/book/2021/978-4-297-12307-9)

- **3章 共通鍵暗号**
- **08 共通鍵暗号**
  - 「強秘匿性」
    - 暗号文から平文を推測できない性質
  - 「選択平文攻撃 CPA (Chosen Plaintext Attack)」
    - 平文とその暗号文のペアを、盗聴者が入手できてしまう性質を突いた攻撃
  - 「ブロック暗号」
    - 平文を一定の固まりごとに暗号化
  - 「ストリーム暗号」
    - 平文全体を暗号化
- **09 ビットと排他的論理和**
- **10 乱数**
  - 乱数生成と疑似乱数生成
    - 乱数生成は、ゼロから乱数を生み出すもの
      - `/dev/random`
    - 乱数生成器は、シードから乱数を生み出すもの
    - シードを乱数生成で作り、それを乱数生成器で使うのが一般的
      - `/dev/urandom`
- **11 ワンタイムパッド**
  - OPT (One-Time Pad)
  - 平文と同じ大きさの秘密鍵のXORを取り、暗号文を作る
  - 秘密鍵が漏れない限り絶対に安全
  - 秘密鍵を安全に送れるのであれば平文を安全に送ればいいじゃん、という...
- **12 ストリーム暗号**
  - 「ストリーム暗号」
    - シードを秘密鍵としてワンタイムパッドを使う方法
  - シードの長さ分の安全性
    - `2^シードの長さ`
    - 「ブルートフォース攻撃」
      - 秘密鍵を片っ端から試す
    - n=128くらいあれば十分に安全
  - 「ナンス (nonce)」
    - シードに更に加えるランダム値
  - 「ChaCha20」
    - 最新のストリーム暗号
- **13 ブロック暗号**
  - 「AES」
    - （方法については省略）
- **14 確率的アルゴリズム**
  - 「確率的アルゴリズム」
    - 決定的アルゴリズムの入力の一部が乱数なもの
  - 暗号化アルゴリズムは確率的アルゴリズムにすべし
    - ＝暗号化アルゴリズムは入力の一部を乱数にすべし
- **15 暗号化モード**
  - AESのブロックを暗号化する方式はいくつかある
  - 「ECB (Electronic CodeBook) モード」
    - 決定的アルゴリズムである。確率的アルゴリズムでない。
    - 同じブロックならば暗号化したブロックも同じになってしまって、あまり安全ではない
    - パターンが解読されてしまう
  - 「CBC (Cipher Block Chaining) モード」
    - 一つ前の暗号化ブロックのXORを取ってから暗号化する
  - 「CTR (CounTeR) モード」
    - まず`nonce+0, nonce+1, nonce+2, ...`らから乱数を作って、それぞれについて平文のブロックとのXORをとり、それを繋げたら全体の暗号化となっている
      - 相手には「暗号文」と「ナンス」を送る
    - 各ブロックの並列処理ができる
- **16 ディスクの暗号化**
  - 「TPM (Trusted Platform Module)」
    - セキュリティ専用チップ
  - HDD, SSDなどのハードウェアをまるごと暗号化する機能がOSにはある
    - 暗号化の秘密鍵はTPM内に保存する
  - ハードウェア自身に暗号化・復号化の仕組みが備わっているものもある
- **17 暗号文の改竄とリプレイ攻撃**
  - 暗号化文の改竄は署名で対策
  - 送信の再現の攻撃には通し番号などを含めて対策
