# すごいHaskell：型を信じろ

- [すごいHaskellたのしく学ぼう！](https://shop.ohmsha.co.jp/shopdetail/000000001926/)
- **第2章: 型を信じろ！**
  - `:t`で、式の型を知れる
  - 「多相的関数」
    - 型変数を用いた関数
  - 「型クラス」
    - Rustのトレイトと同じ
  - `ghci> :t (==)`
    - `(==) :: Eq a => a -> a -> Bool`
      - 「型シグネチャ」という
    - この`=>`の右の`Eq a`は「型クラス制約」
      - 型`a`は型クラス`Eq`のインスタンスでなければならない、という意味
  - 型クラスいろいろ
    - `Eq`
      - `==`, `/=`
    - `Ord`
      - `compare`, `<`, `<=`, ...
    - `Show`
    - `Read`
      - evalできるもの
      - `read :: (Read a) => String -> a`
    - `Enum`
      - 列挙できるもの
      - `succ`, `pred`
    - `Bounded`
      - 上限と下限を持つもの
      - `minBound`, `maxBound`
        - `minBound :: Bounded a => a`
    - `Num`
      - 数字は多層定数として表現されている
        - `123 :: Num a => a`
    - `Floating`
      - `sin :: Floating a => a -> a`
    - `Integral`
      - 整数
      - `fromIntegral :: (Integral a, Num b) => a -> b`
        - `Integral`型クラスから`Num`型クラスに緩める関数?
        - `fromIntegral (length [1,2,3,4]) + 3.2`のように使う
  - 「型注釈」
    - 式の終わりに`::`をつけ、その後に式の型（型注釈）を指定
