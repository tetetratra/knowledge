# 計算理論

- [計算理論 (2020年度後学期)](http://dopal.cs.uec.ac.jp/okamotoy/lect/2020/comp/)
  - 計算モデル
    - チューリングマシン
    - オートマトン
    - プッシュダウンオートマトン
    - λ計算
    - WHILEプログラム
    - GOTOプログラム
    - DNAコンピュータ
  - 部分関数
    - 値が存在しない場合もある関数
    - $ f: A \not \rightarrow Bのように書く
    - 逆は全域関数（普通の関数のこと）
  - 計算可能
    - 「fがOO計算可能」のように使う
      - 「関数`f(x,y)=x+y`がWHILE計算可能」など
    - fを模すOOを作ることができるとき、fはOO計算可能
      - 「OOを作る」とは、WHILEプログラムを作ることであったり、チューリングマシンを設計することであったり
  - チャーチ・チューリングの定立
    - 『一般的な「計算可能」のことを、チューリングマシン等で計算可能であることとみなしましょう』という提唱
  - チューリング完全
    - チューリングマシンで計算可能なことを計算モデルMが計算可能なとき、Mはチューリング完全
  - 計算不可能な部分関数の存在
    - 模すことができない部分関数の存在
    - `diag(i) = ( P[i](i) が停止しないなら0, 停止するなら定義されない )`計算可能と仮定する(`P`はありうるプログラムの列挙)。`P[i] = diag`となる`i = j`がどこかにあって、そのとき`diag(j) = (diag(j)が停止しないなら0(= diag(j)が停止する), 停止するなら定義されない(= diag(j)が未定義))`となって矛盾
    - なので`diag`は計算不可能で、計算不可能な部分関数が存在することが示せた
  - 万能関数
    - インタプリタ
    - 頑張れば作れる
  - 停止性問題
    - プログラムとその入力が停止するか判定する関数は計算不可能
    - 証明は難しいからパス...
  - チューリングマシンの認識可能、判定可能について
    - 「言語Lはチューリング認識可能」のように使う
    - 認識可能
      - 言語を受理するチューリングマシンが存在すること。L(M)となるMが存在すること。
    - 判定（＝計算）可能
      - 認識可能 ＋ 必ず停止する
