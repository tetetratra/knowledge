# Linux: インストールとシステムツール

| ファイルシステム |  |
| Linuxでは全てのファイルとディレクトリに iノードという番号を割り振っている |  |
| ファイル名とファイルの中身が対応しているのではなく、iノード番号とファイルの中身が対応している |  |
| iノードごとにファイルの所有者、ファイルの種類、アクセス許可、アクセス 時刻、リンク数、データ領域へのポインタが保持されている |  |
| `ls -i`で確認できる |  |
| ファ イルの詳しい情報は fstatシステムコールで取得できる |  |
| ファイルをリンクする方法は、ハードリンクとシンボリックリンクの 2 種類があり、それぞれ`ln`, `ln -s`コマンドで新たに作る |  |
| ハードリンクを作ることは、iノードを指すファイル名を新たに作ること |  |
| 全体のファイル数は増えず、被リンクファイルとリンクしたファイルに順序、親子関係等は無い |  |
| シンボリックリンクを作 ることは、リンク先のパスを持つファイルを作ること |  |
| シンボリックファイルというものが 新たに作られ、そのファイルの中身にリンク先パスを保持している |  |
| ファイルのサイズについて、ブロックと呼ばれる量を1単位として扱っている |  |
| 書き込み等でファイルサイズが増えるとき、1ブロック分の領域をまとめて確保している。OSXの環境ではブ ロックサイズは4kB |  |
| プロセス、プロセスグループ、セッション について |  |
| [プロセスグループ・セッションについて勉強した - ほげほげ日記](http://yktwww.hatenablog.com/entry/2015/06/07/031523) |  |
| [Ctrl+Cとkill -SIGINTの違いからLinuxプロセスグループを理解する \| ギークを目指して](http://equj65.net/tech/linuxprocessgroup/) |  |
| 「プロセス、プロセスグループ、セッション」の順で大きなまとまり。プロセスが最小単位 |  |
| パイプで繋げるとそれらのプロセスは同じプロセスグループになる |  |
| forkとかで子のプロセス作ったときも同じプロセスグループ |  |
| Ctrl+Cでは、端末を制御しているttyが、Ctrl+CをSIGINTシグナルに変換して、プロセスグループの各プロセスにSIGINT送信している |  |
| `kill -2 12345`では、指定したプロセスにのみSIGINTを送っている |  |
| 普段ジョブと呼んでいるものはプロセスグループのこと |  |
| `setsid`コマンド |  |
| 新規セッションでプログラムを動かす |  |
| [setsid - システム管理コマンドの説明 - Linux コマンド集 一覧表](https://kazmax.zpp.jp/cmd/s/setsid.8.html) |  |
| sshでパスワードを自動化 |  |
| [expectやsshpassを使わずにシェルでSSHパスワード認証を自動化する - Qiita](https://qiita.com/wadahiro/items/977e4f820b4451a2e5e0) |  |
| sshが実行されたセッションに関連付けられたターミナルが存在しない時に、`SSH_ASKPASS`で指定したプログラムを実行してパスフレーズを読み取る |  |
| `setsid`で新規セッションでsshを実行すれば、関連付けられたターミナルは無いので、SSH_ASKPASSが使われる |  |
