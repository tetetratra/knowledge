# Linux: ファイルシステムとプロセスセッション

| ファイル入出力操作の画一化 |  |
| ファイルの入出力や端末への出力等、あらゆる外側との入出力をファイルディ スクリプタとみなし、画一的に扱う |  |
| open システムコールでは、ファイルだけでなく端末への入 出力 (stdin/stdout) も開くことができ、read や write システムコールもそれに対しての読み込み、書き込みが行える |  |
| プロセスが開いているファイルディスクリプタは、`/proc/(プロセス ID)/fd/` にある。 |  |
| ファイルのようにアクセスできる入出力にはキャラクタデバイスとブロックデバイスの2 種類がある |  |
| キャラクタデバイスは、読み書きはできるが seek(読んだファイルポインタを戻すこと) はできないデバイス |  |
| ターミナルの画面やキーボード等 |  |
| ブロックデバイスは、ランダムアクセスができるデバイス |  |
| SSD,HDDなど、一般的なデータ保存デバイス |  |
| 後述の ファイルシステムを経由して操作する |  |
