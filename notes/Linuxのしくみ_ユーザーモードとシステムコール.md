# Linuxのしくみ：コンピュータシステムとユーザーモード

- **第1章　コンピュータシステムの概要**
  - デバイスドライバがある。複数プロセスの同時アクセスとかを防ぐ
  - カーネルモードで動く
  - カーネルモードの機能を使うにはシステムコールを利用する
- **第2章　ユーザモードで実現する機能**
  - straceコマンドで、プロセス内で呼ばれたシステムコールを見れる。
  - システムコールのmanは、`man 2 write`でわかる
  - `sar`コマンドで、CPUのユーザーモードとカーネルモードの割合がわかる
  - C言語にはISOによって定められた標準ライブラリがある
