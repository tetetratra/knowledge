# フレームワーク

- 漠然とした課題があるとき、「目的」を更に下記の3つに分解して定義するとよい
  - **成果 / Outcomes**
    - 視点：実施者
    - 実際に得られたアウトプット
    - 何ができたか
  - **成功基準 / Success Criteria**
    - 視点：組織や関係者
    - 成果が十分かどうか
    - 「評価軸」「達成ライン」
  - **提供価値 / Value**
    - 視点：利用者・顧客の視点
    - 相手にとって何が嬉しいか
- 思考フレームワークの一覧
  - **緊急度・重要度マトリクス**
  - **GROWモデル**
  - **バリューチェーン分析の社内運用版**
  - **AIDMA**
  - **KPIツリー**
  - **SMART**
  - **PERT図**
  - **RACI**
  - **ムリ・ムラ・ムダ**
  - **ECRS**
  - **動機づけ・衛生理論**
  - **PREP**
