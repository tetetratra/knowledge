# 言語処理系

- BNF
  - backus naur form
  - バッカス記法
- 非終端記号
  - 最終結果には現れないもの
  - `<`,`>`で囲まれたもの
- 終端記号
  - 最終結果には現れるもの
  - `1`, `+` とか
- 超記号
  - BNFを表現するための記号
  - `:=`, `<`, `>`, `|` とか
- 導出
  - 非終端記号を、生成規則の右辺に置き換えること
  - 具体的な感じになる
- 最左導出
- 左の非終端記号から導出する
- 最右導出
- 右の非終端記号から導出する
- 還元
  - 導出の逆の操作
  - 抽象的になっていく
- 右結合
  - 同じ二項演算子が連続して出てきた時、右の方のほうが結合が強いこと
  - `1 + 2 + 3` は、`1 + (2 + 3)`と解釈
  - 生成規則が右再帰(**自身の再帰が右辺の右側に現れる**)だとこれになる
  - `⟨term⟩ ::= ⟨0以上の数⟩ | ⟨0以上の数⟩ * ⟨term⟩`
- 左結合
- 右結合の逆
- **自身の再帰が右辺の左側に現れる**
- `⟨term⟩ ::= ⟨0以上の数⟩ | ⟨term⟩ * ⟨0以上の数⟩`
- 上向き構文解析
  - 還元を繰り返して解析していく
  - 最右導出の逆順の繰り返し
  - yaccというツールで解析プログラムを作れる
- 下向き構文解析
  - 再帰下降法
  - 最左導出の繰り返しをしていく
- 字句解析
  - 最小単位に分けていく
- **Yaccについて**
  - Yaccとは
    - 上向き構文解析を行うCプログラムを自動作成するツール
    - yet another compiler compiler
    - YaccのGNU版をbisonという
  - 構文解析のための2つのスタック
    - 記号スタック
      - トークン・非終端記号が入る
    - 構文解析スタック
      - 現在の状態が入る
  - Yaccの基本操作
    - シフト
      - 現在注目している字句を記号スタックに積み、現在の注目点を1つ進める。
    - 還元
      - 記号スタックの上(先頭寄り)の記号列を還元して、還元後の非終端記号に置き換える
- 「シフト還元構文解析」や「LR構文解析」と呼ぶ
- 2つの表を使う
- 動作表
- 「今の状態」と「今の字句」から次の動作を決める
- 次の動作は2種類
- シフト
- 現在の状態を指定した状態に変更して、その状態を構文解析スタックに積む
- 還元
- 現在の構文解析スタックからいくつかポップし、指定した構文規則で還元する。
- その後、行先表から次の状態を決める
- 行先表
- 動作表による還元後、現在の状態と還元後の非終端記号から次の状態を決める
- 「構文規則」にも番号が振られているし、「状態」にも番号が振られているから混乱しがち
- **流れ**
  - loop
    - 構文解析スタックのtopを見る(･･･ 行)
    - 「次の字句」を見る(･･･ 列)
    - 動作表のその行・列の指示を見る
      - シフトなら
        - 「次の字句」を記号スタックにpush
        - 注目点を進める(「次の字句」が更新される)
        - 構文解析スタックに、そのシフトで指定された状態をpush
        - continue
      - 還元なら
        - 記号スタックの先頭からその構文規則の右辺個分取り出して、還元したものに置き換える
        - 記号スタックから取り出した右辺個、構文解析スタックでもpopする
        - 構文解析スタックのtopを見る(･･･ 行)
        - さっき還元した、還元後の非終端記号を見る(･･･ 列)
        - 行先表のその行・列を見て、そこで指定された状態を構文解析スタックにpushする
        - continue
- **アセンブリ言語へコード生成**
- x86のアーキテクチャを対象にコード生成
  - スタックに値や番地を入れていって計算
    - 番地は大きい方から小さい方で伸びていく
  - スタックポインタespレジスタ
    - 関数呼び出し直後は ebp=esp になる
    - 関数呼び出しの中で上下に動く
  - ベースポインタebpレジスタ
    - ebpの指すアドレスには旧ebpが指していたアドレスが入る
    - 関数呼び出しの最中は同じ場所を指している
  - eaxレジスタ
    - 関数の返り値を入れるレジスタ

- **使い方**
  - lexファイルの使い方
    - 字句解析、終端記号の解析
    - `lex`コマンドでlexファイルをコンパイルすると、`.yy.c`ファイルができる(Ｃ言語のファイル)
      - `yylex()`関数が作られる。返り値はlexファイルの右側で指定した定数とか
    - このC言語ファイルをメインのCプログラムでincludeする
    - そしてメインのCプログラムを、`cc foo.c -ll`とコンパイル
      - `-ll`はlexのライブラリを指定している
  - yaccファイルの使い方
    - 非終端記号の解析
    - `yacc`コマンドでyaccファイルをコンパイルすると、`.tab.c`ファイルができる(C言語)
      - これは、`yylex()`関数を呼ぶことでlexで解析した終端記号を読み込んでいる
    - このC言語ファイルをメインのCプログラムでincludeする
      - `yyparse()`で解析を始める
    - `cc piyo.c -ll -ly`でコンパイル
      - `-ly`でyaccライブラリを指定
  - yaccの機能
    - `$n`で(nは1から)、マッチしたn番目の属性値が入る
    - `$$`に左辺の非終端記号の属性値を入れる
      - `$n`数値とかなら実際に足したりしたものを`$$`に入れる
  - 変数
    - 記号表という、変数名と値の構造体の配列を使って実現
  - 構文木
    - 種類、値(or 左)、右(or NULL) の構造体の配列で実現
    - ノードを作る関数は、自身の配列内での添字をindexとすることで、親に自身を渡している
