# 新 管理職1年目の教科書

- 第1章 迅速な意思決定のルール
  - RULE01 「いつまでに決めるか」を決める - 「慎重な人」のままでは無能扱いされる
  - RULE02 迷ったときは「目的」に立ち返る - 情報が多いほど意思決定の精度が上がるという勘違い
  - RULE03 **「失敗したらこうしよう」と事前に決めておく** - 「失敗したらどうしよう」と思うから不安がなくならない
  - RULE04 「ここまでやったのだから」は1ミリも続ける理由にはならない - 「コンコルド」の失敗と「インテル」の成功に学ぶ
    - **サンクコストを考えない**
  - RULE05 10分で結論を出せないときは誰かと話す - 考えているつもりで、実は迷っているのだから
  - 【COLUMN】外資系企業が評価するのはサバイバル力がある人材
- 第2章スピード感を生む仕事のルール
  - RULE06 どんな仕事でもすぐに**「ちょっとだけ」やってみる** - 爆速で仕事を進める人の必殺技
  - RULEO7 会議の「オーナーシップ」を発揮する - 必ず結論を出すための米国流会議の進め方
  - RULE08 会議の参加者自身に次のアクションを宣言させる - 「それ、私がやることになっていたの？」と絶対に言わせない
  - RULE09 「即断・即返信」で常に相手側に仕事を渡しておく - 遅い返信では、判断力のない人だとバレる
  - RULE10 報告書は事前に半分書いてしまう - 「空欄効果」で論点整理を行う
  - RULE11やり方ではなく考え方を伝える - A4一枚にまとめるために、縮小コピーをする行為を見過ごさない
  - 【COLUMN】「この瞬間から、直ちにだ！」
    - これは同意できなかった
- 第3章 生産性を高める仕事のルール
  - RULE12 「いた方がいいから」で部下を会議に参加させない - 組織にはびこる「あった方がいい病」が生産性を低下させる
  - RULE13 「質」とは完成度ではなくニーズへの合致性である - 独りよがりの高品質追求に価値はない
    - イシューからはじめよ 「isssue度 ✕ 解の質」
  - RULE14 仮説・検証のループで早く正解にたどり着く - 「とにかくやってみる」だけでは熱意のカラ回り
  - RULE15 評価する人ではなく自問する人になる - アイデアを生み出す人の思考習慣
  - RULE16 「当たり前」の水準を高めて涼しい顔で仕事をする - 無能な人ほど「忙しい」「難しい」「大変だ」とアピールする
  - RULE17 情報共有で劇的に生産性を高める - 「車輪の再発明」というムダを多発させていないか
    - Working Out Loud
  - RULE18 「ダブルメリット話法」で健全に上司をころがす - 自分の理屈で話している限り上司のイエスは引き出せない
    - >提案を上司の業務目標に関連づける
  - 【COLUMN】シカゴの高校の「不合格」ではなく「未合格」
- 第4章 正しく権限委譲を機能させるルール
  - RULE19 できない人に任せてできるようにする - 「任せられる人がいない」と嘆く人の勘違い
  - RULE20 **任せるときには判断基準を共有する** - 裁量権を与えただけでは権限委譲とは言えない
  - RULE21 迷わず介入すべき3つの局面 - 「任せたからには口を出さない」という根拠のない信頼はアダになる
  - RULE22 フィードバックは時間差なしで行う - 「あとでまとめて」は成長機会の制奪になる
    - > 任せてもらったことを粋に感じて前向きに取り組んでいるうちはいいのですが、ふと、「やり損では？」と思われたりしないためにもこの点を忘れてはなりません。
  - RULE23 「君ならできる」という安易な言葉は信用されない - 尻込みする部下には「君だからできる」で根拠を伝える
    - 部下データベースを作る
      - 根拠を持って「君ならできる」と伝えるため
  - RULE24 無敵の人材価値「マネジメントができる専門家」を目指す - マネジメントに専念するほど人材価値は低下する
  - 【COLUMN】「ねえねえ、聞かせてよ」と迫ってくる外国人社員たち
- 第5章自律型人材を育成するルール
  - RULE25 「結果を出せ」ではなく「いますべきことは何か？」と問う - 成功確率を高める冷静な状況判断
  - RULE26 自分が行った判断の根拠を部下に質問する - その場で上司の思考を追体験する実践学習
  - RULE27 部下の「頑張ります」には「どう頑張るか」を問う - 「頑張ってくれ」では部下の思考は停止する
  - RULE28 「イエスの文化」で主体性を引き出す - 上司の否定的な反応は部下の行動を弱化させる
  - RULE20 **弱点には目をつぶって強みを伸ばす** - 相互補完のチームワークで1＋1を3にする
    - (各々が完璧を目指すのではなく) お互いが弱点をカバーし合うようなチームがよい
  - RULE30 「優秀な部下には自由にやらせる」と考えて放置しない - 超一流をぶつけて成長意欲に火をつける
  - 【COLUMN】ボーナス時期のCEOとの攻防戦
- 第6章最強チームを構築するルール
  - RULE31 チームの存在意義を自分の言葉で語る - 業務目標だけでは燃え尽きてしまう
  - RULE32 「問いの共有」でリーダーシップのきっかけをつくる - すべてのリーダーシップが自発的に発揮されるわけではない
  - RULE33 チームの「行動原則」を明らかにする - 上司がどう反応するかという不安を取り除く
  - RULE34 「個人的には反対なのだが」と部下の前では言わない「これで行こう！」と戦闘モードで鼓舞する
  - RULE35 ユルい「心理的安全性」はチームをダメにする - 仕事の基準を高めて挑戦心をかき立てる
  - RULE36 合い言葉は「誰もがリーダー、誰もがサポーター」 - リーダーシップの総量が増えれば組織も人も強くなる
  - 【COLUMN】決してファイティング・ポーズを崩さない米国人
