# Analyzing Permission Transfer Channels for Dynamically Typed Languages

-  2021
- [Analyzing Permission Transfer Channels for Dynamically Typed Languages - Archive ouverte HAL](https://hal.archives-ouvertes.fr/hal-03347573/)
- > Abstract : CSP (Communicating Sequential Process) は、スレッドやプロセスがチャネルを介してデータを交換することで通信する、最近人気のある並行処理モデルである。チャネルは並行処理のオーケストレーションに役立つが、データ競合を解決することはできない。チャネルモデルにおけるデータ競合を防ぐため、多くのプログラミング言語では、所有権や不変性などの動作制限を表現するために型システムに依存しています。しかし、動的型付け言語では、コンパイル時に型情報を持たないため、ランタイム機構が必要となる。本論文では、4つの異なる許可転送セマンティクスを持つチャネルを拡張することを提案する。このような許可転送を実行時に実装するために、書き込みバリアと部分読み出しバリアという2つの機構を検討する。我々のアプローチを検証するために、Pharoにチャネルフレームワークを実装し、それを異なるパーミッション転送セマンティクスで拡張した。(a)単一オブジェクトとオブジェクトのグラフにおける転送オーバーヘッド、(b)所有権チェックで発生するオブジェクト単位のアクセスオーバーヘッドの性能測定結果を報告します。この研究は、許可転送チャネルの適応的最適化に関する将来の研究の基礎となるものです。
