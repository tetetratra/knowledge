# ウィンドウ関数

- 行セット全体ではなく**特定の窓（範囲）に対して演算を行う**ための関数
- [PostgreSQL 9.4.5文書 第 9章関数と演算子 ウィンドウ関数](https://www.postgresql.jp/document/9.4/html/functions-window.html)
  - >これらの関数に加え、どんな組み込み、またはユーザ定義の通常の**集約関数**もウィンドウ関数として使用できます
    - `COUNT`や`SUM`とかも使える
**ウィンドウ関数**

| 関数 | 説明 |
| --- | --- |
| ROW_NUMBER() | 1から数えたパーティション内の現在行の数 |
| RANK() | ギャップを含んだ現在行の順位で、その最初の（対となる）ピアのrow_numberと同一 |
| DENSE_RANK() | ギャップを含まない現在行の順位で、この関数は（対となる）ピアグループ数を計算する |
| PERCENT_RANK() | 現在行の相対順位。 (rank - 1) / (総行数 - 1) |
| CUME_DIST() | 現在行の相対順位。 (先行する行または現在の行を持つピアの番号) / (総行数) |
| NTILE(num_buckets integer) | できるだけ等価にパーティションで割り算した、1から引数値までの整数 |
| LAG(value anyelement) | パーティション内の現在行以前のoffset行である行で評価されたvalueを返します |
| LEAD(value anyelement) | パーティション内の現在行以降のoffset行である行で評価されたvalueを返します |
| FIRST_VALUE(value any) | ウィンドウフレームの最初の行である行で評価されたvalue を返す |
| LAST_VALUE(value any) | ウィンドウフレームの最後の行である行で評価されたvalue を返す |

- [PostgreSQL 9.4.5文書 第 4章SQLの構文 評価式](https://www.postgresql.jp/document/9.4/html/sql-expressions.html#SYNTAX-WINDOW-FUNCTIONS)
**構文.sql**

```
function_name ([expression [, expression ... ]])
  [ FILTER ( WHERE filter_clause ) ]
  OVER window_name

function_name ([expression [, expression ... ]])
  [ FILTER ( WHERE filter_clause ) ]
  OVER ( window_definition )

function_name ( * )
  [ FILTER ( WHERE filter_clause ) ]
  OVER window_name

function_name ( * )
  [ FILTER ( WHERE filter_clause ) ]
  OVER ( window_definition )
```

**window_definitionの構文.sql**

```
[ existing_window_name ]
[ PARTITION BY expression [, ...] ] -- グループ化
[ ORDER BY expression -- ソート
  [ ASC | DESC | USING operator ]
  [ NULLS { FIRST | LAST } ] [, ...]]
[ frame_clause ]  -- ウィンドウフレームを指定
```

**frame_clauseの構文.sql**

```
{ RANGE | ROWS } frame_start -- RANGEはカラムの値， ROWSはソートした結果の行番号
{ RANGE | ROWS } BETWEEN frame_start AND frame_end
```

**frame_startおよびframe_endの構文.sql**

```
UNBOUNDED PRECEDING -- 先頭の行
value PRECEDING -- valueの前の行(RANGEのとき), 現在行よりvalue行前(ROWSのとき)
CURRENT ROW -- 現在の行 (frame_endを省略する場合にはこれが設定される)
value FOLLOWING -- valueの後の行(RANGEのとき), 現在行よりvalue行後(ROWSのとき)
UNBOUNDED FOLLOWING -- 末尾の行

```

**例.sql**

```
SELECT
  id, name,
  xxx(*) OVER (
    PARTITTION BY name
    ORDER BY name
    RANGE BETWEEN
  )
FROM tbl;

```

**累積.sql**

```
select
  "日付",
  "ページビュー",
  SUM("ページビュー") OVER(
    ORDER BY "日付"
    ROWS UNBOUNDED PRECEDING
  ) as 累積 
from v_収益
```

**差分.sql**

```
select
  "日付",
  "ページビュー",
  LAG("ページビュー", 1) OVER(
    ORDER BY "日付"
  ) as １つ前の値
from v_収益
```

**移動平均.sql**

```
-- 4行前から現在までの平均を計算している
select
  "日付",
  "ページビュー",
  AVG("ページビュー") OVER(
    ORDER BY "日付"
    ROWS BETWEEN
        4 PRECEDING
      AND
        CURRENT ROW
  ) as 移動平均 
from v_収益

```

- [第89回　WINDOW関数を使ってみる \| gihyo.jp](https://gihyo.jp/dev/serial/01/mysql-road-construction-news/0089)
  - `PARTITION BY` は `GROUP BY` と似たような感覚の操作
  - フレーム：パーティションのうちどの範囲を扱うか
    - 例
      - `ROWS UNBOUNDED PRECEDING` → 全範囲
      - `ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING` → 前後1行
  - windowには名前をつけることができて、再利用できる
- MySQL5.7の、ウィンドウ関数が無い環境でウィンドウ関数のrankのような計算をしたいときは、1:1で紐づくようにクエリを一段階ラップして絞り込み用のカラムを渡せばOK
  - 例：`user_id`でGROUP BYしたグループのうち、`date`カラムが一番新しいレコードの`status`を知りたい
```sql
SELECT
  h.status -- こうやって取る
FROM histories AS h
JOIN (
  SELECT
    user_id,
    MAX(date) AS max_date -- 外側のクエリに絞り込み用の値を渡してあげる
  FROM histories
  GROUP BY user_id
) AS sub
  ON sub.user_id = h.id
  AND sub.max_date = h.date; -- ここで1:1で紐付ける
```

- **「内：外 ＝ 1：1」となるようにwrapする**という考え方は他の状況でも役に立つかも知れない
