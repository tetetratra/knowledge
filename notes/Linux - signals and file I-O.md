# Linux: シグナルとファイル入出力

| 割込み処理 |  |
| シグナルという仕組みがあり、プロセスの外側からプロセスに割り込むことができる |  |
| シグナルが送られると、実行中のプロセスは停止され、シグナルが送られたプロセスに処理が移る |  |
| 代表的なシグナル |  |
| `SIGINT` |  |
| フォアグラウンドでプロセスが実行中のとき、Ctrl-C で渡すことができる。プロ セスを止める一般的な方法 |  |
| `SIGQUIT` |  |
| フォアグラウンドでプロセスが実行中のとき、Ctrl-\で渡すことができる |  |
| `SIGALRM` |  |
| プロセスの処理時間を扱うときに使われるシグナルである |  |
| `SIGTSTP` |  |
| プロセスを一時停止する際に使われる。Ctrl-Z で送ることができ、プロセスをバックグラウンドに移し、一時停止させる |  |
| `SIGTERM` |  |
| kill コマンドでデフォルトで送られるシグナル |  |
| `SIGKILL` |  |
| プロセスを強制終了させたいときに送る。後述のフック処理を利用しても捕捉されず、プロセスが終了させられる |  |
| `SIGHUP` |  |
| bash 等の端末プロセスが終了した際に、その子プロセスに送られるシグナル |  |
| プロセスはプログラム中にフックすることができ、C言語では signal 関数でフック処理を登録できる |  |
| 端末プロセスを終了した際、その子プロセスに SIGHUPシグナルが送られ子プロセスも終了場合が多いが、`nohup`コマンドを利用するとその SIGHUP プロセスが送られないようになり、バックグラウンドで処理を動かしたい時に有用である。 |  |
