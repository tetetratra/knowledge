# Call-trail Dependent Inline Caching for a Scoping Mechanism of Class Extensions

-  2018
- [Call-trail Dependent Inline Caching for a Scoping Mechanism of Class Extensions](https://ipsj.ixsq.nii.ac.jp/ej/?action=pages_view_main&active_action=repository_view_main_item_detail&item_id=185718&item_no=1&page_id=13&block_id=8)
- >Method Sealsのメソッドディスパッチ性能を向上させるため、コールトレイルに依存したインラインキャッシングを提案する。Method Sealsは、クラス拡張の有効範囲をユーザが手動で制御することができるクラス拡張機構である。既存のクラス拡張機構よりも優れた安全性を提供する。しかし、インラインメソッドキャッシュがないため、Method Sealsのランタイム性能は不満足なものとなっています。Method Sealsでインラインキャッシュを可能にするために、従来のインラインキャッシュ機構にコールトレイル依存性を追加しました。そのために、コールパスに沿ったクラスの集合を表すコールトレイルの概念を導入しました。固定長のビットセットを用いて、現在のコールトレイルとメソッド定義の未シールパッケージリストを表現する。また、本提案を実現するために、Method Sealsのセマンティック制約を適宜緩和した。さらに、提案するコールトレイルに依存したインラインキャッシングをMethod Seals上に実装し、その性能をベンチマークした。
