# 探索アルゴリズム

- ドメイン知識を使うのがヒューリスティック探索、ブラインド探索
  - ブラインド
    - 深さ優先探索
      - 超巨大な木では使えない
    - 幅優先探索
    - 反復深化法
      - 徐々に深くしていく深さ優先探索
    - 均一コスト探索
      - ダイクストラ法と同じロジックで、経路が短い順に探索
  - ヒューリスティック
    - 貪欲法
      - グラフとは関係無い情報(直線距離とか)を基準にしたり
    - A*アルゴリズム
      - 評価関数`h(n) + g(n)`で貪欲法
        - `g(n) = (スタートからノードnまでの最短経路)`
          - 確定済みの値
        - `h(n) = (ノードnからゴールまでの最短経路の近似値)`
          - 近似の部分にヒューリスティックを使う
      - 全てのノードで`h(n) <= (ノードnからゴールまでの最短経路)`(許容的ヒューリスティック)なら、最適な解が見つかる
