# アセットヘルパー

- https://railsguides.jp/action_view_helpers.html#アセットヘルパー
  - `javascript_pack_tag` とかの、suffixが`_tag`のメソッドのことをアセットヘルパーという
    - > アセットヘルパーは、ビューから「画像」「JavaScriptファイル」「スタイルシート（CSS）」「フィード」などのアセットにリンクするHTMLを生成する一連のヘルパーメソッドを提供します。
  - デフォルトでは `public/` 配下のアセットが使われるが、アセット専用サーバーを見るように設定も可能
  - 素のrailsが提供するタグ
    - JS
      - `javascript_include_tag("common") # => <script src="/assets/common.js"></script>`
        - Sprocketsが提供
        - 主に従来型のRailsプロジェクト（Webpackerを使わない場合）で使われる
        - `app/assets/javascripts` (`vendor/assets/javascripts`, `lib/assets/javascripts`も) 配下を読み込む]
        - `/assets`配下に出力
    - CSS
      - `stylesheet_link_tag("application") # => <link href="/assets/application.css" rel="stylesheet" />`
        - Sprocketsが提供
    - その他
      - `favicon_link_tag # => <link href="/assets/favicon.ico" rel="icon" type="image/x-icon" />`
      - `image_tag("icon.png") # => <img src="/assets/icon.png" />`
    - Sprocketsが提供でスクリプトのrequireをするときは `//= require`
  - webpackerが提供するタグ
    - JS
      - `javascript_pack_tag`
        - `app/javascript/packs` 配下を読み込む
        - `/packs` 配下に出力
    - CSS
      - `stylesheet_pack_tag`
    - その他
      - `image_pack_tag`
    - スクリプトのrequireは `import`または`require`
- 新しいやつにImportmapsやesbuildもあるけれどよくわからぬ
