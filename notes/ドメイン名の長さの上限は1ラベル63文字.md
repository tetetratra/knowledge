# ドメイン名の長さの上限は1ラベル63文字

- ドメイン名には、ラベル（ドットで区切った各部分）ごとの上限と、全体の上限がある
  - ラベルは63オクテットまで（[RFC 1035 2.3.4 Size limits](https://datatracker.ietf.org/doc/html/rfc1035#section-2.3.4)）
  - 全体は255オクテットまでで、長さを表すバイトを含むため、ドット区切りの文字列としては実質253文字
  - URL のホスト名もメールアドレスのドメイン部も、同じ制限を受ける
- メールアドレスの検証ライブラリが、これらの上限まで見ているとは限らない
  - たとえば Ruby の valid_email2 では、1ラベル64文字以上のドメインも通った
