# JWT

- JSON Web Token
  - 中身はドットで繋がれた3つのハッシュ値
    - `[ヘッダ].[ペイロード(中身)].[署名]`
  - 「署名」があるので、(受信側は)本当に本人から送られたものかの検証はできる
  - 暗号化はされていないので、
  - ヘッダとペイロードは、生のヘッダとペイロードをBase64したドットでつなげたものなだけ
    - Base64でエンコーディングすることは決まっている
  - 生ヘッダも生ペイロードも、JSON形式のものに対してBase64化する
  - `[ヘッダ].[ペイロード(中身)]`に対して、(例えばSHA256などで)(秘密鍵を使って)ハッシュ化したものを`[署名]`として末尾に付けたら完成
    - 署名するときのハッシュ化方式はヘッダで指定できる
  - 受信側は、公開鍵で`[ヘッダ].[ペイロード(中身)]`と`[署名]`を検証することで、正しい送信者からのデータだということがわかる
  - 暗号化はされていないので、受信側は誰であってもBase64で`[ヘッダ].[ペイロード(中身)]`をデコードすれば中身が見れる
