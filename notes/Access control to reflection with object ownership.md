# Access control to reflection with object ownership

- from ACM
-  2015
- [Access control to reflection with object ownership | ACM SIGPLAN Notices](https://dl.acm.org/doi/10.1145/2936313.2816721)
- >リフレクションは、言語拡張、汎用コード、動的解析、開発ツールなどを可能にする強力なプログラミング言語機能である。しかし、制御されないリフレクションはオブジェクトのカプセル化を破壊し、プログラムの攻撃対象領域を大幅に増加させる。例えば、悪意のあるライブラリはリフレクションを利用してクライアントアプリケーションを攻撃することができる。リフレクションとオブジェクトのカプセル化を一緒にするために、我々は動的なオブジェクトの所有権を用いて、リフレクション操作へのアクセス制御ポリシーを設計する。このポリシーはオブジェクトに、それらが所有するオブジェクトに対する完全な反射力を与えるが、他のオブジェクトに対する反射力は制限される。コードはまだ高度な反射操作を使うことができるが、反射はもう攻撃ベクトルとして使われることはない。
