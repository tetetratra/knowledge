# AWS Savings Plan

- AWS
- Savings_Plan
  - 種類がある
    - Compute Savings Plans
      - 時間単位で計算され、AWS 全体で消費するコンピューティングリソース（EC2、Fargate など）に対して適用。
      - FargateやEC2のインスタンス(やlambdaにも)に自動で適用される
    - EC2 Instance Savings Plans
      - 特定のインスタンスタイプ（例: m5.large）やリージョンに対して適用。
  - SPは、「期間を指定して、その期間中、時間あたり◯◯ドルまで使う分はSPから払える」という仕組み
    - なので、サービスに急激な一時的なスケールアウトなどが起きてしまうと、その分はSPでは賄えない(= オンデマンド料金がかかる)
    - SPは余っていそうなのにオンデマンド料金がかかっている場合はこういう理由の可能性がある
  - マネジメントコンソールで、推奨金額が見れるので、それに従って買うのが楽
