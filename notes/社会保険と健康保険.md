# 社会保険と健康保険

- **PART5 社会保険のしくみ**
  - 事業主と従業員で折半
  - 健康保険と厚生年金保険はセットで手続きされがち
  - 事業所単位
  - 会社の場合は社長とかも含めて全員が被保険者となる
  - 個人事業者の場合は被保険者になれない
    - 「適用除外」
  - 給与額から保険料が決まる
    - 定時改定の手続きで報酬を申告
      - 社会保険では給与のことを報酬という
      - 「健康保険・厚生年金保険被保険者報酬月額算定基礎届（算定基礎届）」
      - 「健康保険。厚生年金保険被保険者報酬月額算定基礎届総括表」
    - 賞与を出したときも申告
      - 「健康保険厚生年金保険被保険者賞与支払届」
  - 従業員に関する色々な届出
    - 入社時
      - 「雇用保険被保険者資格取得届」
      - 「健康保険被保険者資格取得届」
      - 「健康保険被扶養者（異動）届」
        - 雇った人に被扶養者がいるとき
    - 氏名の変更
      - 「健康保険厚生年金保険被保険者氏名変更（訂正）届」
    - 扶養の追加（配偶者）
      - 「健康保険被扶養者（異動）届」
    - 住所変更
      - 「健康保険厚生年金保険被保険住所変更届」
      - 扶養者の住所変更なら
        - 「国民年金第3号被保険者住所変更届」
    - 扶養の追加（出産）
      - 「健康保険被扶養者（異動）届」
      - 「健康保険出産育児一時金支給申請届」
        - 42万円が支給される
      - 「健康保険出産手当金支給申請書」
    - そのほかのケースでも被扶養者の増減があったとき
      - 「健康保険被扶養者（異動）届」
  - 事業所の移転や事業主の変更のときとかも各種届出が必要
  - 源泉徴収
    - 所得税を給与から予め引いておくこと

- **PART6 健康保険のしくみ**
  - 健康に関することでもらえる
  - 業務中なら労災保険。業務外なら健康保険
  - 運営によって保険の呼び方が違うらしい
    - 「全国健康保険協会」が保険者の健康保険は「全国健康保険協会管掌健康保険（協会けんぽ）」
    - 「健康保険組合」が保険者の健康保険は「組合管掌健康保険」
  - 健保と国保
    - 健康保険と国民健康保険は別物
    - 国民健康保険
      - 自営業者、無職者が入る
      - 市区町村が保険者
  - 被扶養者になる条件
    - 年収130万未満
    - 保険者の年収の半分以下
    - 別居の場合、被扶養者の年収が仕送りより少ないこと
  - 保険金が支給されるのは本当に病気や怪我のときだけ
    - 少しでも適用外の治療が入ってくると全部適用外になる
    - 最先端の治療などは保険外併用療養費といい、併用OKだが、この部分の治療費は保険の対象外となる
  - 三割負担
  - 高額の治療には高額療養費が給付される
    - 額は年収に逆進
    - 月収28~50万だと、医療費が`8万 + (総医療費 - 27万) * 0.01`を超えた分が支給される
  - 介護費用にも高額治療に似たような制度がある？
    - 高額治療と介護費用を合算して限度を超えると更にもう少しもらえる
  - 業務外の怪我で働けなくなった場合は傷病手当金がもらえる
    - 収入の2/3を、1年6ヶ月目までもらえる
  - 出産の場合も、怪我とは別の制度だけれども、休業分の収入と一時金がもらえる
  - 被保険者も2~3割負担で医療を受けられる
  - 会社の退職後は、自分で保険を選んで入る必要がある
    - すべての国民は医療保険に入らねばならないという法律がある
    - 選択肢
      - 任意継続保険者になる
        - 退職後も2年間その会社のときの健康保険に入れる
      - 扶養者側になる
      - 特例退職被保険者？ になる
      - 国民健康保険に入る
  - 収入の1割くらいが保険料で、事業者と折半だから5%くらい
