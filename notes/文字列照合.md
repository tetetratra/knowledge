# 文字列照合

- xがyの接頭辞のとき、$ x \preceq_p y  と書く。$
  - 接尾辞のとき、$ x \preceq_s y$
  - 部分文字列のとき、$ x \preceq_{sub} y$
  - 文字列照合問題
    - 入力：$ |p| \le |t|  を満たす文字列p,t$
    - 出力：pがtにおいて現れるすべての出現位置
