# ディスプレイ

- https://ja.wikipedia.org/wiki/画面解像度
**用語**

| 呼び方 | 縦×横 | メモ |
| --- | --- | --- |
| HD | 1280×720 | 基準値。最近は見ない |
| フルHD, FHD | 1920×1080 |  |
| 4K | 3840×2160 | よく聞くやつ。FHDの4倍の画素数 |

- YouTubeなどの画質の数値は、横のピクセル数を指している
- ppi
  - 密度の単位
  - 1インチあたりのドット数
- 縦横それぞれ2倍になるとき、ピクセル数は面積なので4倍になる
