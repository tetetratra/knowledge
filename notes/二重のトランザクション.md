# 二重のトランザクション

- 二重のトランザクションは、**張れる**
  - [何番煎じかわからないけどRailsのトランザクション処理について  - Qiita](https://qiita.com/u110/items/e087f34878ca9aabee5b#%E3%83%8D%E3%82%B9%E3%83%88%E3%81%97%E3%81%9F%E5%86%85%E9%83%A8%E3%81%A7-activerecordrollback-%E3%81%8C%E8%B5%B7%E3%81%8D%E3%81%A6%E3%82%82%E4%BC%9D%E6%90%AC%E3%81%95%E3%82%8C%E3%81%AA%E3%81%84)
  - が、注意が色々ある
    - 注意1: `raise ActiveRecord::Rollback`した場合、外側のトランザクションにはそれが伝わらず(内側のトランザクションで消化されてしまう)、全体的にはコミットされて、**内側のトランザクションはrollbackされない**
```rb
User.transaction do
  User.create(username: 'Kotori')
  User.transaction do
    User.create(username: 'Nemu')
    raise ActiveRecord::Rollback
  end
end
# 例外通知こない
# User.all.count ==> 2
```

- 注意2: 他のエラー (`raise StandardError`など) であれば外側のトランザクションまで伝播して、全部rollbackされる
```rb
User.transaction do
  User.create(username: 'Kotori')
  User.transaction do
    User.create(username: 'Nemu')
    raise StandardError
  end
end
# 例外通知来る
# User.all.count ==> 0
```

- 注意3: `joinable: false`は非推奨なので使わない
