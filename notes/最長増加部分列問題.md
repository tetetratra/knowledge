# 最長増加部分列問題

- 数列の数値をいくつか消すと増加列なら、それは増加部分列
  - 部分構造最適性
    - 大きな部分問題の最適解の部分構造が小さな部分問題の最適解になっている
  - 自身より短い列での最大、でDP
    - 式だとO(n^2)だけどメモ化とかすればO(n)のはず
**最長増加部分列**

```
l(i): 最終要素がa_iで終わる最長増加部分列
l(i) = max { l(j) + 1 | 0 <= j < i, l(j) < l(i) }
L = max { l(i) | 1 <= i <= n }

```
