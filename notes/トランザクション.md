# トランザクション

- トランザクション内で「テーブルにある行の情報を取得する」「その行に対して更新を掛ける」方法
  - [MySQL 8.0 で NOWAIT / SKIP LOCKED（いまさら）  - Qiita](https://qiita.com/hmatsu47/items/7675b026e65762d2445f)
  - この処理を行う
    - (トランザクションを開始する)
    - `SELECT ... FOR UPDATE`でロックを獲得する
    - （取得した情報を加工するなどして）UPDATEする
    - (トランザクションを終了する)
- `SELECT ... FOR UPDATE`の`NOWAIT`, `SKIP LOCKED` オプション
  - FOR UPDATE SKIP LOCKED
  - [MySQL 8.0 で NOWAIT / SKIP LOCKED（いまさら）  - Qiita](https://qiita.com/hmatsu47/items/7675b026e65762d2445f)
  - `SELECT ... FOR UPDATE` に付けられるオプション
  - 挙動がどう変わるか
    - 何もオプションを付けないとき：ロックが獲得できるまで待つ
    - `NOWAIT`：ロックが獲得できなかったときは即時にエラーを返す
    - `SKIP LOCKED`：即時に獲得可能なロック**_ のみ**獲得して結果を返す
      - `SELECT ...`した結果が複数行あったとき、**その中でロックを獲得できた行のみ**を(即座に)返す
- `FOR UPDATE SKIP LOCKED`はSolidQueueで使われている
